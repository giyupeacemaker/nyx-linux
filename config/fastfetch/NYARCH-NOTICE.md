# Nyarch ASCII artwork

`nyarch.ascii` is the compact `ascii50` artwork from the official Nyarch Linux repository:

- Source: https://github.com/NyarchLinux/NyarchLinux/blob/main/Gnome/etc/skel/.config/fastfetch/ascii50
- Upstream repository: https://github.com/NyarchLinux/NyarchLinux
- Upstream license: GNU GPL v3 (see the repository LICENSE)

It is included as an optional visual reference for this personal build. It is not the name or branding of this distribution, and the build does not claim to be an official Nyarch Linux release.
