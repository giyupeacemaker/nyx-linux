# Nyx Linux

Arch-based дистрибутив, поставляемый как загрузочный ISO с графическим
установщиком. Установщик работает прямо с образа: загрузитесь, выберите рабочий
стол, и он поставит рабочую систему на ваш диск.

Репозиторий: <https://github.com/giyupeacemaker/nyx-linux>

Лицензия: Apache License 2.0, см. [LICENSE](LICENSE). Сторонние компоненты и
позиция по торговым маркам — в [NOTICE](NOTICE).

## О проекте

Nyx Linux сейчас на стадии pre-alpha. Баги будут, и какое-то время название
Arch Linux в названиях пакетов будет читаться странно.

Есть планы перейти с systemd на OpenRC, но не раньше, чем выйдет стабильный
релиз: сначала один-три стабильных релиза на systemd, и только потом смена
init-системы.

Это, прежде всего, энтузиастский проект, который ведёт один человек и
AI-агент, который помогает с репозиторием.

## Что внутри

- Arch Linux userland и официальные репозитории `core`/`extra`.
- Репозиторий CachyOS подключён **после** Arch-репозиториев, поэтому обычные
  пакеты берутся из Arch, а из CachyOS доступны `linux-cachyos` и
  AUR-помощники.
- Calamares 3.4.3 с графическим интерфейсом на KDE Plasma.
- Live-окружение: KDE Plasma, SDDM, Calamares, NetworkManager.
- Выбор рабочего стола: KDE Plasma, GNOME, XFCE, MATE, Cinnamon, Budgie,
  LXQt, Deepin, Enlightenment, Pantheon, Sway, Hyprland, i3 или минимальная
  система.
- Выбор AUR-помощника: Yay, Paru или не устанавливать.
- Выбор загрузчика: Limine (по умолчанию), systemd-boot или GRUB.
- Поддержка LUKS и ручной разметки.
- `fastfetch` в live-сессии и в установленной системе.
- Устанавливаемая система: минимальная Arch-based база с `git`, `curl`, `wget`,
  `sudo`, `base-devel`, NetworkManager и шрифтами.

## Требования

| | |
| --- | --- |
| Режим загрузки | только UEFI, разметка GPT |
| Secure Boot | должен быть отключён |
| Архитектура | x86_64 |
| Свободное место | минимум 20 ГБ |
| Оперативная память | минимум 4 ГБ |

Legacy BIOS не поддерживается и не будет поддерживаться.

## Получение образа

Скачайте образ и сверьте его с опубликованной контрольной суммой перед записью
на флешку:

```bash
sha256sum -c nyx-linux-alpha-01.09.2026-x86_64.iso.sha256
```

Пишите в режиме DD (Rufus, balenaEtcher), чтобы образ был записан дословно.

## Установка

1. Создайте тестовую VM и подключите образ.
2. Загрузитесь в UEFI. Calamares должен открыться автоматически через SDDM.
3. Выберите рабочий стол, AUR-помощника и загрузчик.
4. Для обычной установки выберите `Erase` и GPT. Ручная разметка тоже доступна.
5. Оставьте UEFI, `/boot` на ESP и желательно LUKS2 для root.
6. После завершения **извлеките исходный образ из VM перед перезагрузкой**,
   иначе UEFI может продолжить загружать установочный диск.

Обязательно проверьте установщик в виртуальной машине, прежде чем применять
его на настоящем железе, и сделайте резервную копию диска.

Выбор загрузчика обрабатывает `nyx-configure-bootloader`:

- **Limine** — ставит NVRAM-запись, fallback `EFI/BOOT/BOOTX64.EFI` и меню;
- **systemd-boot** — пишет `loader/entries/10-nyx-linux.conf` и вызывает
  `bootctl install`;
- **GRUB** — `grub-install --target=x86_64-efi`, затем `grub-mkconfig`.

Все три варианта читают `/etc/fstab` и `/etc/crypttab`, поэтому корректно
собирают командную строку ядра для btrfs-подтомов и LUKS.

Тема и меню Limine лежат в `config/limine-bg.png`; конфигурация обновляется
pacman hook после обновления ядра.

## Название и fastfetch

- `ID=arch` — совместимость с Arch-based пакетами сохранена намеренно;
- `NAME="Nyx Linux"`;
- `PRETTY_NAME="Nyx Linux (Arch-based)"`;
- `VERSION_ID` соответствует дате сборки.

Обычное обновление `filesystem`/`base` может вернуть `/usr/lib/os-release` к
оригиналу Arch, поэтому pacman hook автоматически восстанавливает брендинг Nyx,
сохраняя `ID=arch`.

По умолчанию:

```bash
fastfetch          # пресет Nyx
fastfetch -c arch  # обычный Arch-пресет
```

Первая строка вывода — `user@host`: в live-сессии это `archiso@nyx`, после
установки ваш пользователь на `nyx`. Хостнейм по умолчанию — `nyx`, он прописан
и в live-образ, и в устанавливаемую систему.

Раскладка модулей пресета позаимствована из сообщества:
<https://github.com/LierB/fastfetch> (`presets/nyarch.jsonc`).

Логотип подключён файлом, а не картинкой через графический протокол kitty:
живая и установленная системы работают на Plasma, где konsole этот протокол не
понимает, и картинка не отрисовалась бы вообще.

## Важные ограничения

- Только UEFI/GPT; Legacy BIOS не поддерживается.
- Установщик нужно тестировать в отдельной VM перед установкой на физический
  компьютер.
- Репозиторий CachyOS остаётся в установленной системе для обновления
  `linux-cachyos`; порядок репозиториев специально оставлен Arch-first.
- Перед физической установкой сделайте резервную копию диска.

## Юридическая информация

Arch Linux и CachyOS — торговые марки своих проектов. Nyx Linux —
самостоятельный производный дистрибутив. Он не связан с ними, не одобрен ими
и не должен выглядеть официальным образом Arch Linux или CachyOS, и ни один из
этих проектов не ревьюил и не одобрял его.

`ID=arch` в `os-release` установленной системы проставлен намеренно: это
утверждение о совместимости пакетов, а не о принадлежности, и именно оно
позволяет обычному пакету Arch встать без изменений.

Вся графика оригинальна. Логотип — серп из горизонтальных полос,
генерируемый скриптом `scripts/make-logo.py`, и braille-надпись в
`config/fastfetch/nyx.ascii` сделаны специально для этого дистрибутива. Ни то,
ни другое не получено из существующих персонажей или логотипов.
